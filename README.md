📦 ダウンロードされるコンポーネント
本プロジェクト初回実行時に、以下のバイナリを自動ダウンロードする機構があります：

scrcpy.exe（Windows 向け）

adb.exe（必要に応じて）

その他、動作に必要なライブラリ

これらは公式の配布元から取得され、改変は行っておりません。

⚠ 注意事項
本ツールは scrcpy を再配布・改変せず、そのままバイナリを公式から取得・実行します。

scrcpy のバージョンアップにより動作に影響が出る可能性があります。

scrcpy に関する不具合は Genymobile/scrcpy の Issues をご確認ください。
